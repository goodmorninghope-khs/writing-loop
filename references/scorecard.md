# 점검표 (④ 점검에서 회차마다 채운다)

```
글쓰기 루프 점검 · {글 제목} · {N}회차 · 경로 {종류}
A 사실 게이트: 통과/실패 — 대조 {k}건 중 불일치 {m}건 / humanize 게이트 exit {0|1|2}, 변경률 {x}%
B 문체 5축: 직설성 _/10 · 리듬 _/10 · 신뢰 _/10 · 진정성 _/10 · 밀도 _/10 = __/50
C 목적 적합: Clarity ○/△/× · So What ○/△/× · Prove It ○/△/× · Specificity ○/△/× · 독자 질문 막힘 {있음/없음}
D 기관 게이트: {켠 게이트별 통과/실패와 걸린 문장}
판정: 통과 / 미달 → ①|②|③ (이유 한 줄)
```

## A 사실 게이트

- 숫자·날짜·고유명사·직함·인용문을 하나씩 근거 목록(원문)과 대조한다. 원문에 없으면 지우거나 "[확인 필요]"로 바꾼다.
- 완료·진행·예정·계획을 원문 그대로 구분했는지 본다.
- humanize-korean의 verify_gates.py 결과를 적는다. exit 2면 그 윤문본은 쓰지 않는다.

## B 문체 5축 (stop-slop, 각 10점)

| 축 | 묻는 것 | 한국어에서 보는 것 |
|-|-|-|
| 직설성 | 말하나, 예고만 하나 | "~에 대해 살펴보겠습니다", "결론적으로" 같은 머리말 |
| 리듬 | 문장 길이가 섞였나 | 같은 어미(~다. ~다. ~다.) 세 번 이상 연속, 첫째·둘째·셋째 |
| 신뢰 | 독자를 믿나 | 같은 말 되풀이, 지나친 완곡·변명 |
| 진정성 | 사람이 쓴 말 같나 | 번역투(~를 통해, ~에 있어서), "시사하는 바가 크다" |
| 밀도 | 뺄 게 있나 | 형식명사(것·점·부분), 빈 수식어 |

40점 이상이 통과. 짧은 메시지는 사용자 동의 시 35점.

## C 목적 적합

- copy-editing GUIDE의 Seven Sweeps에서 Clarity(한 번에 읽히나), So What(독자에게 왜 중요한가), Prove It(주장마다 근거가 있나), Specificity(막연한 말 대신 구체적인가)를 본다. 홍보 글은 나머지 셋(Voice and Tone, Heightened Emotion, Zero Risk)도 본다.
- 문서는 doc-coauthoring Stage 3 Reader Testing: subagent(default)에 글만 주고 독자가 물을 질문 3~5개에 답하게 한다. 답이 틀리거나 막히면 ①로 되돌린다.

## D 기관 게이트 (routes.md에서 켠 것만)

**평가문체** (policy-media-desk style-and-selection A를 기준 원본으로 읽는다)
- 쓰지 않는 말: 없다, 않았다, 부족하다, 미흡, 늦었다, 아직, 공백, 사각지대, 허점, 과제가 남았다, 이어지지 않는다, 담당이 없다 / 앞섰다, 뒤처졌다, 못 미친다 / 문제는 ~이다, ~가 시급하다, ~해야 한다, ~하라, ~할 것 / 중랑구 부서·사업을 지목해 판단하는 문장.
- 흐름: 다른 곳의 방법 → 나아진 것·한계 → "우리 일에 붙여 보면". 중랑은 이미 하고 있는 일을 먼저. 끝은 질문이나 "~해 볼 수 있겠습니다".
- 문장마다 "이 사업 담당자가 읽으면 평가받는 느낌일까?" 제목도 본다.

**씨날**: 정책 글의 각 신호·제안에 교차점 꼬리표(AX① 주민과 함께 · AX② 민생과 산업 · AX③ 일상 돌봄 · AX④ 일하는 방식 · AX⑤ 검증과 나눔 × 공약 ① 교육 ② 경제·도시개발 ③ 동북권 교통 ④ 주거환경 ⑤ 문화 ⑥ 복지 ⑦ 걷기 좋은 도시). 제안은 그 전략과 공약을 한 걸음 더 나아가게 하는 쪽인가. 사업명은 원문으로 확인될 때만.

**사해의**: 사실(원문), 해석, 의견·제안이 문장 단위로 섞이지 않았나. 의견은 의견이라고 밝혔나.

**보도10**: briefing-twin.md 변환 규칙 10. 특히 자평 수식어(쾌거·성공적·대폭·획기적·큰 호응·~로 자리 잡았다) 제거, 제목은 장소·대상·변화·숫자로, 단체장 이름·사진 노출 줄이기.

**선거법**: 지자체 사업계획·실적·활동 홍보물이 주민 대상으로 배포되나? 그렇다면 분기별 1종 1회 한도와 선거일 전 180일 금지를 보고에 적고 "선관위 질의 필요"를 올린다. 직원 직무교육·업무추진용(공직선거관리규칙 제47조 예외)인지 함께 적는다. 판단은 사용자 몫.
